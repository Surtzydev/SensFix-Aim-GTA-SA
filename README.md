# [ENG] SensFix Targeting Android GTA:SA

Aim sensitivity system for SA-MP. Mechanic that changes weapon aim sensitivity, with the option to set a different sensitivity for each weapon. MonetLoader 3.6.0-os+.

## Features

- Mechanic that changes weapon aim sensitivity
- Set a different sensitivity for each weapon
- PT/EN/ES translation

## Commands

- `/sensfix` - OpenS

## Support

- MonetLoader 3.6.0-os+
- SA-MP 0.3.7
- Architectures arm64-v8a (64-bit) and armeabi-v7a (32-bit)

Requires MonetLoader 3.6.0-os+ and SA-MP 0.3.7

# [PT-BR] SensFix Android GTA:SA

Sistema de sensibilidade de mira para SA-MP. Mecânica que altera a sensibilidade da mira das armas, com opção de configurar uma sensibilidade diferente para cada arma. MonetLoader 3.6.0-os+.

## Funcionalidades

- Mecânica que altera a sensibilidade da mira das armas
- Configuração de sensibilidade diferente para cada arma
- Tradução PT/EN/ES

## Comandos

- `/sensfix` - Abre as configurações

## Suporte

- MonetLoader 3.6.0-os+
- SA-MP 0.3.7
- Arquiteturas arm64-v8a (64-bit) e armeabi-v7a (32-bit)

Requer MonetLoader 3.6.0-os+ e SA-MP 0.3.7
